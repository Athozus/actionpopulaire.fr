

## Liste de tâches 

Nous maintenons une liste de tâches dans la partie [issues](https://github.com/lafranceinsoumise/actionpopulaire.fr/issues) que vous pouvez
prendre en main.
Vous êtes libres de faire des propositions via la même page.


## Faire une contribution

1. Récupérer le projet en suivant les [instructions](https://github.com/lafranceinsoumise/actionpopulaire.fr?tab=readme-ov-file#mise-en-place-du-projet)
2. À partir d'une [issue](https://github.com/lafranceinsoumise/actionpopulaire.fr/issues), créer une branche correspondant à votre résolution en suivant les [conventions suivantes](https://conventional-branch.github.io/) - [Comment créer une branche à partir d'une issue](https://docs.github.com/fr/issues/tracking-your-work-with-issues/using-issues/creating-a-branch-for-an-issue)
3. Réalisez les changements nécessaires sur la branche précédemment créée
4. Ajouter un test (en Python)
5. Faire une pull request avec la branche en [notifiant la notification](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue) 
6. A chaque push sur une branche, une CI est déclenchée avec les tests, assurez-vous que tout fonctionne correctement, sinon il n'y aura pas de réponse à votre proposition.
7. Attendre les retours et validations :)
